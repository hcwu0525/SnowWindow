# DSSAT 指南

返回 [README](../../README.md)。

## 安装与校验

适配器默认查找 `.tools/dssat/4.8.6.2/`。至少需要 `dscsm048`、
`DSSATPRO.L48`、官方玉米试验模板、品种/生态型/物种文件和 `SOIL.SOL`。
路径较短的要求、本地补丁和构建步骤见
[DSSAT 详细运行说明](../dssat.md)。

官方示例仅验证运行时，不代表 G2F 科学结果。
引擎源码与官方数据需自行取得并确认独立许可，仓库不自动安装或代办授权。
除自身源码外，适配器记录可执行文件、模板、品种/生态型/物种、土壤与
profile 的 SHA256，安装变化后不能沿用旧实验冒充同一输入。

## 输入映射

- 天气：辐射、最高/最低温度和降雨写入 `G2F.WTH`。
- 试验：基于官方 `UFGA8201.MZX` 模板替换站点、播期、密度和管理。
- 品种：固定参考品种 `IB0035`。
- 土壤与肥料：固定 `IB00000007` 深砂壤土，播期 120 kg N/ha。

天气策略更新（2026-10-27）：与 AquaCrop/APSIM 统一，只使用本实验
`normalized/weather.parquet` 中的 G2F `full_year` 原始分表标准化记录；
不读取 legacy POWER CSV/provenance，不需要外部天气缓存。先读当前环境，
只有 `simulation.scan_horizon: cross_year` 且
`continuation_weather_by_environment` 显式映射下一年同站点 G2F 环境时
才追加；无映射不自动替代。`G2F.WTH` 由该请求生成；
模型输入/结果缓存及断点恢复保留，不是外部天气缓存。
forecast 仍用 G2F 历史同站点情景，不用目标年未来实测选参。

## 可校准参数

| 参数 | 含义 |
| --- | --- |
| `P1` | 出苗至幼期结束的积温参数 |
| `G2` | 每株潜在籽粒数 |

当前版本不支持站点级校准。

## 输出解释

从 `Summary.OUT` 读取 `ADAT`、`MDAT`、`HWAM`、`CWAM`。只有存在有效
成熟日期的结果才标记 `matured`；未成熟和失败状态分别保留。

## 已知限制

- 土壤、基因型、初始水氮和施肥日程不是 G2F 实测。
- `ADAT` 与花粉观测只是代理比较。
- 全年扫描是反事实情景，全部成熟不证明冬季播种田间可行。
- 模拟受实际天气截止日限制并记录尾部截断，内部缺日期/核心值仍保留失败。
  2024 相关模拟与 scan/forecast 候选播期不得晚于 2024-11-10（315 天，
  保留 2/29）；7/12–7/14 核心缺测不得补零、外部替代或改标成熟。
  此数据截止日不等于 forecast 信息截止日；见[快速上手](../getting-started.md)。
- 没有 `MOH2_2024`，不配置或伪造；显式映射不证明 2024 已完整。
- 历史报告为 clone 不包含的本地产物，保留其数值、日期和来源，不追认当前
  策略通过。必须用新 ID 和带 `weather_policy` 的新快照，不能混用旧产物。
