## 临时目录最小链路

自动测试 `test_minimal_cli_pipeline_keeps_inputs_and_failed_records` 使用自建
13 文件夹具和确定性替身模型，实际执行：

```text
audit → prepare → baseline → calibrate → validate → scan → report
  → 重复 run → 独立 forecast → catalog
```

断言输入文件字节不变、输出只在配置的自定义临时目录、配置快照存在、
校准训练 ID 不含评估年、扫描与预测保留未成熟状态和失败原因；
也断言 `run` 不隐式产生 forecast。它证明编排链路，不证明田间精度。

新增回归还覆盖新旧完整天气缓存、迁移布局优先级、不混拼 CSV/provenance、
缺失文件清单、快照重新加载、同 ID 配置冲突、无快照历史目录拒绝接管、
并发原子发布和写失败清理重试。普通 APSIM 测试使用自建结构/占位输入，
没有把真实 Models.dll、官方模板或原生引擎复制入仓库。
